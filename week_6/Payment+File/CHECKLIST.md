# 업로드 / 채팅 / 배포 체크리스트

## 이미지 업로드

- [ ] 관리자 계정으로 로그인한다.
- [ ] 상품 등록 화면에서 이미지 파일을 1장 이상 선택한다.
- [ ] `선택 이미지 업로드`를 눌러 Supabase Storage에 올린다.
- [ ] 업로드된 이미지가 미리보기로 보인다.
- [ ] 같은 상품에 이미지가 3장을 넘지 않는지 확인한다.

## 상품 상세 채팅

- [ ] 상품 상세 화면을 연다.
- [ ] 화면 안에 별도 페이지 이동 없이 문의 채팅 패널이 보이는지 확인한다.
- [ ] 메시지를 전송한다.
- [ ] 4초 정도 지나면 새 메시지가 polling으로 갱신되는지 확인한다.
- [ ] 새로고침 후에도 기존 메시지가 DB에서 다시 보이는지 확인한다.

## 배포

- [ ] Vercel 환경변수 `DATABASE_URL`을 설정한다.
- [ ] `SUPABASE_URL`과 `SUPABASE_SERVICE_ROLE_KEY`를 설정한다.
- [ ] `SUPABASE_STORAGE_BUCKET`을 확인한다.
- [ ] `npm start`가 로컬에서 정상 실행되는지 확인한다.
- [ ] Vercel 배포 후 메인 페이지가 열리는지 확인한다.
- [ ] 이미지 업로드 후 공개 URL로 바로 보이는지 확인한다.
- [ ] 상품 상세에서 채팅 폴링이 동작하는지 확인한다.
