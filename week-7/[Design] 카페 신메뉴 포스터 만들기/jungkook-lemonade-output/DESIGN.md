# DESIGN.md - Golden Lemonade K-pop Mood Poster

Design intent:
- K-pop 보컬 무드의 골든 스테이지 조명 + 레몬에이드 실사풍 비주얼 중심 포스터.
- 실제 연예인/로고 없이 팬메이드 콘셉트로 안전하게 구성.

System decisions:
- Palette: `#FFD84D` / `#111111` / `#FFF8E8`
- Fonts: `Black Han Sans` + `Pretendard`
- Canvas: 1080 x 1350
- Main visual: 실사풍 레몬에이드 이미지가 포스터 50% 이상
- Text layer: 모든 텍스트는 HTML/CSS 레이어 배치

Build target:
- single HTML poster app (`index.html`)

Review checklist:
- 메인 카피 5초 가독성
- 가격/기간 정보 명확성
- 권리/안전(실명/로고/얼굴복제 금지) 준수
