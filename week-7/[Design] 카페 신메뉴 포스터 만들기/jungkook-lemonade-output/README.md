# jungkook-lemonade-output

K-pop 보컬 무드 기반 `골든 레몬에이드` 포스터 산출물.

## 실행

```bash
node server.mjs 4183
```

URL:

`http://127.0.0.1:4183/`

## 산출물

- `index.html`
- `exports/jungkook-lemonade-poster.png`
- `exports/jungkook-lemonade-poster.pdf`
- `SUPERVISOR_REVIEW.md`

## 권리/안전

- 실제 정국 사진/실명 로고/공식 이미지는 사용하지 않았다.
- 비공식 팬메이드 콘셉트이며 실제 광고물이 아니다.
