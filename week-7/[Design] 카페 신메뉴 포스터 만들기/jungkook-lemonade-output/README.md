## 실행

```bash
node server.mjs 4183
```

URL:

`http://127.0.0.1:4183/`

## 산출물

- `index.html`
- `assets/premium-grapefruit-ade-gpt-image2.png`

## 권리/안전

- 실제 인물 사진/실명 로고/공식 이미지는 사용하지 않았다.
- 내부 비교용 가상 카페 포스터이며 실제 광고물이 아니다.
