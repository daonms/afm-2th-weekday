# DESIGN.md - 고메정식당 교대본점 네이버 메뉴 웹앱

## Design Intent

이 산출물은 가상 카페 메뉴판이 아니라 `고메정식당 교대본점`의 네이버 지도 메뉴 탭을 참고한 웹앱형 메뉴판이다. 사용자가 제공한 네이버 지도 place/1593583520 링크를 Playwright로 열어 2026.05.04 메뉴 화면을 캡처했고, 그 화면에서 직접 보이는 메뉴와 가격을 우선 반영했다.

## Concept

- 주제: 고메정식당 교대본점 네이버 메뉴 웹앱
- 분위기: 숙성고기 전문점, 깔끔한 교대역 직장인 맛집, 점심특선 강조
- 타겟 손님: 네이버 지도에서 메뉴를 확인하는 방문 예정 손님, 저녁 회식 손님, 점심특선 손님
- 주요 기능: 메뉴 검색, 카테고리 탭, 대표 메뉴 배지, 메뉴 담기, 주문 요약

## Layout

- Desktop web app: 좌측 브랜드 패널, 중앙 메뉴 카드 그리드, 우측 주문 요약 패널
- Mobile: 브랜드 패널, 검색/탭, 메뉴 카드, 고정 주문 요약 순서
- 메뉴 카드는 네이버 플레이스 메뉴 탭처럼 이름, 설명, 가격, 썸네일 영역으로 구성
- 탭: 전체, 한우, 돼지고기, 대표

## Components

### Menu Card

- 대표 메뉴 배지와 카테고리 배지를 사용한다.
- 네이버 메뉴 화면에서 확인한 썸네일 이미지를 카드 이미지로 삽입한다.
- 가격은 카드 하단에서 명확하게 보이게 배치한다.

### Filter And Search

- 검색어는 메뉴명과 설명을 대상으로 즉시 필터링한다.
- `대표` 탭은 네이버 대표 메뉴와 점심특선 시그니처를 함께 보여준다.

### Order Summary

- 메뉴 카드의 `+` 버튼으로 담기
- 수량 조절과 합계 계산
- 실제 결제 기능은 없으며 매장 확인 안내 문구를 둔다.
