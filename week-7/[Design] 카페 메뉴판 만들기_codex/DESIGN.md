# DESIGN.md - LiLo Coffee Roasters 한국어 메뉴판

## Design Intent

LiLo Coffee Roasters 공식 사이트의 스페셜티 로스터 분위기를 한국어 메뉴판으로 재구성했다. 사이트에서 강조하는 매월 3-4종 원두 출시, 계절의 향, 오사카 블렌드, 다양한 추출 도구를 메뉴 구조의 중심으로 삼았다.

## Layout

- 형식: 웹에서 바로 볼 수 있는 세로형 메뉴판
- 상단: 브랜드명, 한국어 소개문, GPT 생성 커피 이미지
- 중단: Seasonal / Osaka / Brewing / Gift 특징 요약
- 본문: 시그니처, 추출 메뉴, 원두와 선물 메뉴
- 우측: 향미 지도와 주문 가이드
- 모바일: 1열로 자연스럽게 접히는 반응형 구성

## Visual Direction

- 배경은 아이보리 종이 질감에 가까운 색으로 설정했다.
- 커피 브라운만 반복하지 않고 레드, 그린, 블루, 골드를 향미 태그에 나눠 사용했다.
- 제목은 세리프 계열로 로스터의 수공예 느낌을 살리고, 본문은 산세리프로 읽기 쉽게 정리했다.
- 이미지는 메뉴판에 직접 들어가므로 텍스트와 로고 없이 제작했다.

## Menu Structure

- Signature Cups: 사이폰 게이샤, 오사카 시즌 블렌드
- Brewing Menu: V60 핫, V60 아이스, 오리가미, 콜드브루
- Beans & Gifts: 이번 달 뉴 빈, Journey 드립백 3종

## Source Rule

공식 사이트에서 확인한 브랜드/카테고리/추출 방식만 사실 기반으로 사용했다. 메뉴명과 가격은 수업 제출용 한국어 메뉴판에 맞춘 재구성이다.
