# 수업계획서 - Design Agent로 디자인 시스템 만들기

- 과제명: Design Agent Workflow
- 대상: AFM 2기 평일반 Week 7
- 예상 시간: 90-120분
- 방식: 디자인 브리프 작성 -> DESIGN.md 생성 -> 단일 HTML 구현 -> 검토

## 1. 수업 목표

학생은 AI에게 "예쁘게 만들어줘"라고 지시하는 수준을 넘어서, 반복 가능한 디자인 시스템을 만들고 그 시스템을 다음 프로젝트에 재사용하는 방법을 배운다.

수업이 끝나면 학생은 다음을 할 수 있어야 한다.

- 자연어 아이디어를 디자인 브리프로 정리한다.
- 색상, 폰트, 타이포그래피, 간격, 컴포넌트 규칙을 `DESIGN.md`에 기록한다.
- `design-agent`에게 프로젝트 단계별 스킬을 선택하게 한다.
- 단일 HTML 결과물을 만들고 디자인 시스템 적용 여부를 검토한다.
- 이미지 생성 도구는 asset 제작용으로만 쓰고, UI 텍스트와 디자인 토큰은 코드/문서에 남긴다.

## 2. 수업 배경

AI는 Apple, Material, Bootstrap처럼 많이 학습된 스타일은 잘 반복하지만, 개인이나 팀만의 개성 있는 스타일은 지시만으로 안정적으로 반복하지 못한다.

그래서 수업에서는 디자인 시스템을 만든다. 디자인 시스템은 단순한 예쁜 색상표가 아니라, AI가 다음 작업에서도 같은 스타일을 반복할 수 있게 만드는 규칙 묶음이다.

## 3. 실습 주제

학생은 아래 주제 중 하나를 선택하거나 직접 주제를 정한다.

1. 개인 명함 소개 페이지
2. 동아리/스터디 모집 페이지
3. AI 서비스 랜딩 페이지
4. 수업 과제 제출 페이지
5. 포스터형 이벤트 안내 페이지

## 4. 수업 흐름

### 1단계 - 디자인 브리프

사용자는 만들고 싶은 주제, 대상 사용자, 분위기, 반드시 들어가야 할 내용을 자연어로 작성한다.

예시:

```text
design-agent 써서 AI 독서모임 모집 페이지를 만들어줘.
한국어 UI이고, 조용하지만 세련된 느낌이면 좋겠어.
처음에는 단일 HTML로 만들고 싶어.
```

### 2단계 - 디자인 시스템 작성

`design-agent`는 `DESIGN.md`를 만든다.

필수 항목:

- 시각 방향
- 컬러 토큰
- 폰트
- 타이포그래피
- 간격/둥근값/그림자
- 컴포넌트 규칙
- 이미지 생성 규칙
- 다크모드 기준
- AI에게 다시 줄 프롬프트

### 3단계 - 단일 HTML 구현

Codex 작업자는 `student-output/index.html`을 만든다.

구현 조건:

- 브라우저에서 바로 열려야 한다.
- 한국어 UI여야 한다.
- `DESIGN.md`의 토큰을 CSS 변수로 반영해야 한다.
- 최소 3개 이상의 재사용 컴포넌트 패턴이 보여야 한다.
- 이미지가 필요하면 실제 이미지 생성 대신 `gpt-image-2`용 프롬프트를 `ASSET_PROMPTS.md`에 남긴다.

### 4단계 - 감독자 검토

감독자는 결과물을 검토한다.

검토 기준:

- `DESIGN.md`와 `index.html`의 스타일이 일치하는가
- 한국어 텍스트가 이미지가 아니라 HTML/CSS로 들어갔는가
- 색상/폰트/간격/컴포넌트 규칙이 반복되는가
- AI가 만든 것 같은 흔한 스타일을 피했는가
- 다음 프로젝트인 Vite/React 전환이 가능한 구조인가

## 5. 평가 기준

| 항목 | 배점 | 기준 |
|---|---:|---|
| 디자인 브리프 | 20 | 대상, 목적, 분위기가 명확함 |
| DESIGN.md | 30 | 토큰과 컴포넌트 규칙이 재사용 가능함 |
| 단일 HTML 구현 | 30 | 브라우저 실행 가능, 시스템 적용이 보임 |
| 검토와 기록 | 20 | 작업 기록과 개선점이 남아 있음 |
