# Codex 1 작업지시서 - 실제 고메정식당 메뉴판으로 재작업

## 역할

너는 구현 담당 `Codex 1`이다. 기존 결과물은 `고메정식당 카페`로 잘못 재해석되어 과제 범위와 맞지 않는다. 이번 작업은 **카페 메뉴판이 아니라 실제 고메정식당 메뉴를 사용한 식당 메뉴판**으로 전면 수정하는 것이다.

감독자는 별도 검토한다. 임의로 카페 메뉴, 가상 메뉴, 창작 메뉴를 추가하지 않는다.

## 작업 위치

```text
D:\다온\DAON_AI - 문서\afm-2th-weekday\week-7\[Design] 카페 메뉴판 만들기
```

## 핵심 수정 지시

현재 파일의 `고메정식당 카페`, 커피, 논커피, 디저트 메뉴는 모두 과제 범위 오류다.

다음 방향으로 바꿔라.

- 과제명은 그대로 `[Design] 카페 메뉴판 만들기` 폴더를 쓰되, 결과물 주제는 **고메정식당 실제 메뉴판**
- 카페 메뉴 금지
- 실제 고메정식당 메뉴와 가격 사용
- 웹에서 메뉴판 이미지/음식 이미지를 검색해 참고
- 최종 메뉴판은 A4 세로 또는 1080 x 1350
- 시그니처 메뉴는 `직화 제육 쌈밥 정식`
- 시그니처 메뉴는 사진/일러스트 영역 + 강조색으로 시선을 잡기

## 이미지 사용 지시

웹에서 메뉴판/음식 이미지를 검색해서 참고하되, 최종 제출물에 이미지를 직접 삽입할 때는 다음 원칙을 지켜라.

1. `assets/reference/`에 원본 이미지 또는 캡처를 저장한다.
2. `SOURCE_NOTES.md`에 이미지 출처 URL, 캡션, 사용 목적을 기록한다.
3. 저작권이 불명확하면 최종 메뉴판에는 직접 사진을 크게 넣지 말고, 사진을 참고한 CSS/SVG/간단 일러스트 또는 톤앤매너만 사용한다.
4. 그래도 음식 사진을 넣어야 하면 교육 과제용 참고 이미지임을 `SOURCE_NOTES.md`에 명시한다.

## 디자인 방향

카페가 아니라 **고깃집/한식당 메뉴판**이다.

- 분위기: 숙성고기 전문점, 깔끔한 교대역 직장인 맛집, 점심특선 강조
- 타겟 손님: 점심 직장인, 저녁 회식/와인 손님
- 컬러: 3색 이내 유지
  - 한지 크림 또는 미색
  - 숯불 차콜
  - 고기/불향을 상징하는 딥 레드 또는 갈비 브라운
- 폰트: 2개 이내 유지
- 가격은 오른쪽 정렬
- 카테고리는 최소 3개:
  - 점심특선
  - 저녁 소고기
  - 저녁 돼지고기
  - 가능하면 포장/곁들임을 작은 영역으로 추가

## 시그니처 메뉴

시그니처는 반드시:

```text
직화 제육 쌈밥 정식
```

강조 방법:

- 시그니처 박스 또는 오른쪽 패널
- 쌈채소/불향/화로 느낌의 이미지 또는 일러스트
- `불향`, `쌈채소`, `점심특선`, `2인 이상 주문 가능` 중 확인 가능한 문구를 짧게 사용

## 금지사항

- 커피 메뉴 사용 금지
- `고메정식당 카페`라는 이름 사용 금지
- 가상 메뉴 추가 금지
- `직화 크림 라떼`, `고메 아메리카노`, `흑임자 크림 밀크` 등 기존 창작 카페 메뉴 전부 삭제
- 이미지 생성 AI로 실제 메뉴를 대체 금지
