# Skill: Visual Research

## Purpose

Collect and translate visual references into reusable design decisions.

## Use When

- The student references Apple, GitHub, Shopify, Carbon, Material, Polaris, Primer, Shadcn, or another known system.
- The student wants a style inspired by a website, poster, card, or app.
- The class needs 2-3 design directions before choosing one.

## Inputs

- Reference names or URLs
- Target artifact
- What to borrow: mood, layout, color, typography, density, or components
- What not to copy

## Process

1. Extract the visible design signals.
2. Separate reusable system decisions from one-off decoration.
3. Convert references into token candidates.
4. Recommend whether the reference fits the class project level.
5. Record the chosen direction in `DESIGN.md`.

## Output

```text
Reference:
What it teaches:
Reusable tokens:
Component ideas:
Risks:
Recommendation:
```

## Good References By Need

- Admin/table-heavy UI: Shadcn, Ant Design, Carbon
- Developer/product UI: Primer, Polaris, Linear-like systems
- Document/poster: Kami-style constraints
- Single HTML agent UI: Weblet-style static app pattern

## Classroom Rule

Students may borrow structure and token logic, but must not clone a brand identity as-is.
