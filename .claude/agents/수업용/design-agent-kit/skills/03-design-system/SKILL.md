# Skill: Design System

## Purpose

Create or update `DESIGN.md` so future AI generations repeat the same visual language.

## Use When

- A page looks good and the class wants to reuse its style.
- Multiple outputs are starting to drift visually.
- Moving from single HTML to React/Vite or Turborepo.

## Required Sections

1. Visual theme and atmosphere
2. Color palette and roles
3. Typography and font rules
4. Spacing, radius, and elevation
5. Component styling
6. Layout principles
7. Asset and image rules
8. Dark-mode behavior
9. Agent prompt guide

## Process

1. Read the current UI or reference.
2. Extract concrete values, not vibes only.
3. Name tokens semantically.
4. Add do/don't rules for the AI.
5. Add a prompt guide students can paste into agents.

## Output

Update `DESIGN.md` and summarize:

```text
Added tokens:
Added component rules:
Added layout rules:
Known risks:
Next project target:
```

## Classroom Rule

A design system is useful only if another agent can recreate the same style without seeing the original screen.
