# Skill: Single HTML Prototype

## Purpose

Build the first classroom design project as one self-contained HTML file.

## Use When

- Project 1 asks for one page.
- The goal is fast visual feedback.
- No server, build step, or package install should be required.

## Constraints

- One `index.html` file is preferred.
- Inline CSS and vanilla JS are allowed.
- React CDN/Tailwind CDN can be used when the class context already uses them.
- The page must open directly in a browser.
- Keep Korean text in actual HTML/CSS, not inside generated images.

## Process

1. Read `DESIGN.md`.
2. Identify the one most important screen.
3. Build visible design-system evidence: colors, font, components, and layout rhythm.
4. Add only interactions that help the lesson.
5. Leave comments only for classroom learning points.

## Output

```text
File:
What changed:
Design system used:
How to open:
Review checklist:
```

## Classroom Rule

The first project should teach taste and consistency before architecture.
